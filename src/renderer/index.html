    Zephus

    Zephus is a local-first, schema-backed visual editor for Astro websites. Your sites live on your machine and are backed by Git — no external accounts or cloud databases required.

    Third-Party Licenses

    Zephus is free software licensed under GPL-3.0. Source code is available at github.com/BurntToasters/zephus.
