# Zephus 1.0.0 — Verification Artifact

Repeatable E2E proof for the prepared stable 1.0.0 release candidate (not
published yet; this tree is package version `1.0.0` on `main`).

## Repeat

```bash
git fetch --all --prune
node build-scripts/test-all.js --skip-smoke   # unit, compile, lint, format, typecheck, syntax, config, astro-build, coverage, e2e-failures
xvfb-run -a npm run smoke:runtime:fast        # real Electron E2E: save, drafts, publish, git, external-change
npm run test:e2e:all                          # mock-website failure battery across all 10 themes + mutated astro rebuilds
```

Linux headless needs `xvfb`. First Electron launch in a fresh container needs the
sandbox helper fixed once:

```bash
sudo chown root:root node_modules/electron/dist/chrome-sandbox
sudo chmod 4755 node_modules/electron/dist/chrome-sandbox
```

## Results (2026-11-18, accessibility and HID audit batch on 4b9d8b5)

Branch `next-1.0.0` at `4b9d8b5f0ef0d91cbf2afcfe09f10ecd1de0d65d` plus this
batch's working-tree edits: WCAG text-token contrast fixes in
`src/renderer/styles.css`, the new `wcag text token contrast` failure-suite
check in `build-scripts/e2e-failure-suite.js`, and canvas keyboard navigation
(ArrowUp/ArrowDown block traversal with focus follow, Home/End edges, Escape
deselect on both the block and document paths, locked-delete status) in
`editorCanvas.ts`, `editorKeyboard.ts`, `zephusEngine.ts`, `editorSmoke.ts`,
and `HelpModal.tsx`.

On local Windows on 2026-11-18, `npm run test:all -- --skip-smoke
--skip-coverage` passed in 229.3s: unit 1072 passed (17 skipped, the usual
`skipIf(win32)` set), compile, lint (0 warnings), format, typecheck, syntax
(213 checked), config (40 checks), astro build, and e2e failures.

`npm run smoke:runtime:fast` (after `npm run compile:renderer`) printed
`Smoke run: renderer checks passed, shutting down.` and exited 0. The smoke
run now also asserts the new keyboard behavior in real Electron: ArrowDown
selects the next block and moves DOM focus, ArrowUp returns, ArrowDown on the
last block stays put, Home/End reach the page edges, block-level and
document-level Escape both clear the selection state and the rendered
selection, and Delete on a locked block keeps the block and sets a status.

`npm run test:e2e:all` passed 191 / 0 (was 190; the new check is
`wcag text token contrast`, minimum 5.24:1 across all 96 text-token-on-surface
pairs). Artifact:
`artifacts/e2e/4b9d8b5f0ef0d91cbf2afcfe09f10ecd1de0d65d.json`.

Known limitation of the new traversal: it walks top-level blocks only; blocks
nested inside column blocks remain reachable by Tab, not by arrows.
