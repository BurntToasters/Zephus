# Zephus 1.0.0 — Verification Artifact

Repeatable E2E proof for the planned stable 1.0.0 cut (not published yet;
this tree is `1.0.0-beta.1` on `main`).

## Repeat

```bash
git fetch --all --prune
node build-scripts/test-all.js --skip-smoke   # unit, compile, lint, format, typecheck, syntax, config, astro-build, coverage, e2e-failures
xvfb-run -a npm run smoke:runtime:fast        # real Electron E2E: save, drafts, publish, git, external-change
npm run test:e2e:all                          # mock-website failure battery across all 10 themes + mutated astro rebuilds
```

Linux headless needs `xvfb`. First Electron launch in a fresh container needs the
sandbox helper fixed once:

```bash
sudo chown root:root node_modules/electron/dist/chrome-sandbox
sudo chmod 4755 node_modules/electron/dist/chrome-sandbox
```
