# Zephus 1.0.0 — Verification Artifact

Repeatable E2E proof for the 1.0.0 stable cut on branch `next-1.0.0`.

## Repeat

```bash
git fetch --all --prune
node build-scripts/test-all.js --skip-smoke   # unit, compile, lint, format, typecheck, syntax, config, astro-build, coverage
xvfb-run -a npm run smoke:runtime:fast        # real Electron E2E: save, drafts, publish, git, external-change
```

Linux headless needs `xvfb`. First Electron launch in a fresh container needs the
sandbox helper fixed once:

```bash
sudo chown root:root node_modules/electron/dist/chrome-sandbox
sudo chmod 4755 node_modules/electron/dist/chrome-sandbox
```
